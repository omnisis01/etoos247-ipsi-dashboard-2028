# 2028 데이터 검증·최신화 (A 시행계획 대조 · B 변경 공지 · C 전형명 개명)

2026-10-09 정찰 결과와 작업 절차. 사용자 결정 — **전수 수록 35개대부터, A+B+C 함께, 대학별로 끝날 때마다 배포.**

## 왜
우리 2028 데이터는 `2028_수시정시_35개대_의치약한수_260608.xlsx`(2026-06-08 입력, 시행계획 기준)에서 왔다.
서울대 시제품 대조에서 **양쪽에 있는 29단위는 인원이 전부 일치했지만 PDF에만 있는 단위가 6개 173명**(전기·정보공학부 100,
바이오시스템·소재학부 35, 음대·미대 38)이었다 — 즉 전사 오류보다 **단위 누락**이 문제다. 그리고 2027 '지역균형선발전형'→2028
'지역균형전형' 같은 개명 때문에 진짜 증감(서울대 컴공 지역균형 9→19)이 '전형 변경'으로 가려져 있다(1,410행).

## 원천
- **A. 시행계획 PDF** — 메가스터디 대입정보 CDN, 대학별 고정 URL. 파일은 2026-07-01 업로드된 **4월 대교협 심의본**이라
  우리 6/8 엑셀과 같은 세대 → A는 '변경'이 아니라 **전사·누락 검증**이다.
  ```
  https://cdn013.negagea.net/dgsmidc/omr/seoul/web/univ_info2026/<대학명>/<대학명>_2028학년도_대학입학전형계획.pdf
  ```
  (`<대학명>`은 URL 인코딩. 보유 48 + 별칭 5 = 53/75교 → `cdn_coverage.json`. 별칭: 강원대학교(강릉)·(춘천)→강원대학교,
  경상대학교→경상국립대학교, 단국대학교→단국대학교(죽전), 동국대학교(WISE)→동국대학교(⚠️ 서울캠 파일일 수 있음, 확인).)
  미보유 22교는 각 입학처 '대학입학전형 시행계획' 게시물에서 받는다. 어디가 자료실에도 대학별 zip 묶음(가~광·국~ㅁ·ㅂ~을·이~ㅎ)이 있다.
- **B. 6월 이후 변경 공지** — 각 대학 입학처 공지("2028학년도 대학입학전형 시행계획 변경", 예: 한국교원대 2026.6).
  중앙 목록이 없어 **대학별 게시판을 직접** 본다. 검색엔진에는 거의 안 잡힌다.
- **C. 전형명 개명 사전** — 시행계획 PDF에 "2027학년도 전형명 ↔ 2028학년도 전형명" 표가 있는 대학이 있다(연세대 확인).
  `adapt_2028.py` 의 `_EXPLICIT` 같은 개명 사전(`tools/plan28/rename28.json`)으로 만들어 어댑터가 읽게 하면 '전형 변경' 행이 ▲▼로 복원된다.

## 절차 (대학 1곳 = 1단위, 끝나면 배포)
1. `fetch_plan28.py <대학>` — CDN(또는 수동 저장본)에서 PDF → `pdftotext -layout` → `plan28/<대학>.txt`
2. `parse_plan28.py <대학>` — 수시 모집단위×전형 인원 표 추출(대학별 레이아웃이 달라 파서는 대학별 규칙 + 수동 보정).
   서울대 시제품 정규식: `^\s*(단위명)\s+(\d+|·)\s+(\d+|·)\s+(\d+|·)\s+(\d+|·)\s+(\d+)\s*$` (지역균형·일반·기회균형·정시·합계)
3. `diff_plan28.py <대학>` — 우리 data.js(2028)와 (학과·전형) 단위 대조 → PDF에만/우리에만/인원 상이 목록
4. 판정 — PDF 쪽수를 근거로 `data_corrections.json`(enroll/add/drop/rename)에 넣는다. **근거 없는 교정 금지.** 어댑터 산출 중간
   엑셀이 원천이므로 교정 키는 중간 엑셀의 (대학·학과·전형유형·전형명)이다. 2027 교정 650건은 참고 형식(git 이력 3ea810b 이전).
5. B — 그 대학 입학처 공지 확인, 변경이 있으면 같은 채널로 반영(why 에 공지 제목·날짜).
6. C — PDF의 전형명 대조표를 `rename28.json` 에 추가 → `adapt_2028.py` 재실행 → '전형 변경'이 줄었는지 확인.
7. `build_data.py` → 하네스 → `build_ins_2028.py` → `verify_insights` → `--save-baseline`(의도한 변화일 때만) → stamp → commit → push.
8. context-notes 에 대학별 발견·판정을 적는다(2027 요강 전수 대조와 같은 형식).

## 알려진 함정
- 시행계획 PDF 표는 줄바꿈으로 쪼개진 행이 많다 — 파서가 놓친 행을 '우리에만 있음'으로 오판하지 말 것(서울대 시제품에서 광역·자유전공·경영대학 등 27단위가 그랬다).
- 정원외(농어촌·저소득·특수)는 대학에 따라 정시 열에 있다. 수시 합계를 낼 때 열 머리글을 반드시 확인.
- 2028 원천 '35개대' 안에서도 수록률 80% 미만인 대학이 있다(coverage.partial) — 그 대학은 누락 단위가 많을 것이다.
